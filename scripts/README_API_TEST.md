# API 自动化测试脚本使用指南

## 📋 概述

这是 ZK Code Arena 的 API 自动化测试脚本，用于测试所有主要接口的功能和可用性。

## 🚀 快速开始

### 1. 安装依赖

```bash
# 进入 scripts 目录
cd scripts

# 安装 Python 依赖
pip install -r requirements.txt

# 或使用 pip3
pip3 install -r requirements.txt
```

### 2. 确保服务运行

```bash
# 启动服务（在项目根目录）
docker-compose up -d

# 或本地运行
go run cmd/*.go
```

### 3. 运行测试

```bash
# 在 scripts 目录下运行
python api_test.py

# 或使用 python3
python3 api_test.py

# 或在项目根目录运行
python scripts/api_test.py
```

## 🎯 测试重点

### 关键修复验证

脚本会特别验证以下已修复的问题：

1. **TestCase updated_at 字段** 🔴
   - 检查创建的测试用例是否包含 `updated_at` 字段
   - 验证字段格式是否正确

2. **题目更新 500 错误** 🔴
   - 测试更新题目接口是否正常工作
   - 之前会因为双重 $set 导致 500 错误

3. **Swagger 响应结构** 🔴
   - 验证所有接口返回的数据结构
   - 确保不再出现 `{propertyName*: "anything"}` 错误

## ⚠️ 注意事项

1. **确保服务运行**：运行测试前确保 API 服务已启动
2. **账号存在**：确保测试账号已在数据库中创建
3. **网络连接**：确保能够访问 API 服务
4. **权限正确**：确保账号角色配置正确

## 🐛 常见问题

### Q: 提示 "管理员登录失败"
**A:** 检查账号是否存在，密码是否正确，服务是否运行

### Q: 提示 "Connection refused"
**A:** 确保 API 服务已启动，端口 8080 未被占用

### Q: 某些测试失败
**A:** 查看错误信息，可能是：
- 数据库未初始化
- 权限配置不正确
- 接口逻辑有问题

### Q: 彩色输出不正常（Windows）
**A:** 脚本已使用 colorama 支持 Windows 彩色输出，如仍有问题：
```bash
pip install --upgrade colorama
```

## 📚 扩展测试

如需添加更多测试，在 `api_test.py` 中添加测试函数：

```python

    """测试你的模块"""
    print_header("你的模块测试")
    
    tester.test_api(
        "测试名称",
        "GET",  # 或 POST/PUT/DELETE
        "/your/endpoint",
        token=tester.admin_token,
        params={"key": "value"}
    )

# 在 main() 函数中调用
def main():
    # ...
    test_your_module(tester)
```
