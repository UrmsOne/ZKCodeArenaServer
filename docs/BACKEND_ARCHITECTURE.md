## 1. 项目概述

**ZK Code Arena** 是一个基于 Golang 构建的现代化在线编程平台，为仲恺农业工程学院提供题库管理、代码评测、班级课程管理等功能。

### 核心功能模块
- 用户管理（注册、登录、权限控制）
- 题库管理（题目CRUD、分类、难度）
- 代码评测（多语言支持、沙箱隔离）
- 班级课程（课程管理、作业系统）
- 统计分析（用户统计、题目统计）

## 2. 技术栈

| 类别 | 技术 | 版本 | 用途 |
|------|------|------|------|
| **语言** | Go | 1.23+ | 后端主语言 |
| **Web框架** | Gin | latest | HTTP路由和中间件 |
| **数据库** | MongoDB | 4.4+ | 主数据存储 |
| **缓存** | Redis | latest | 缓存和限流 |
| **评测引擎** | go-judge | latest | 代码沙箱评测 |
| **文档** | Swagger/Scalar | latest | API文档生成 |
| **日志** | Logrus | latest | 结构化日志 |
| **容器化** | Docker | latest | 部署和开发环境 |
