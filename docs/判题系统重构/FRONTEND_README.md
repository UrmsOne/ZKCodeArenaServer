## 📋 本次重构概述

### 主要变更

1. **测试用例模型增强**
   - 新增 `time_limit`、`memory_limit`、`score` 字段
   - 支持测试用例级别的超时配置
   - 支持部分分功能

2. **判题结果模型增强**
   - 区分示例用例和隐藏用例
   - 示例用例返回详细信息（output, expected, error）
   - 隐藏用例仅返回状态和资源使用

3. **新增测试用例管理 API**
   - 获取测试用例列表
   - 创建测试用例
   - 更新测试用例
   - 删除测试用例
   - 所有接口需要 JWT 认证

4. **判题流程异步化**
   - 提交后立即返回
   - 通过轮询或 WebSocket 获取结果

## 🛠️ Mock 工具选择

根据你的项目技术栈选择合适的 Mock 方案：

| 工具 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **Apifox** | 团队协作、接口文档管理 | 功能强大、支持自动化测试 | 需要安装客户端 |
| **Mock.js** | 本地开发、快速原型 | 简单易用、不依赖外部服务 | 功能相对简单 |
| **MSW** | 现代前端项目 | 真实网络请求模拟、支持 Service Worker | 配置稍复杂 |
| **Axios Mock Adapter** | 使用 Axios 的项目 | 简单快速、与 Axios 深度集成 | 仅支持 Axios |

详细配置方法请查看 **[FRONTEND_MOCK_GUIDE.md](./FRONTEND_MOCK_GUIDE.md)**

## 🔗 API 端点总览

### 测试用例管理

```
GET    /api/v1/testcase/problem/:problem_id  # 获取题目的测试用例列表
GET    /api/v1/testcase/:id                   # 获取单个测试用例
POST   /api/v1/testcase/                      # 创建测试用例
PUT    /api/v1/testcase/:id                   # 更新测试用例
DELETE /api/v1/testcase/:id                   # 删除测试用例
```

### 题目管理

```
GET    /api/v1/problem/                       # 获取题目列表
GET    /api/v1/problem/:id                    # 获取题目详情
POST   /api/v1/problem/                       # 创建题目
PUT    /api/v1/problem/:id                    # 更新题目
DELETE /api/v1/problem/:id                    # 删除题目
```

### 提交管理

```
POST   /api/v1/submit/                        # 提交代码
GET    /api/v1/submit/:id                     # 获取提交详情
```

### 用户管理

```
POST   /api/v1/user/register                  # 用户注册
POST   /api/v1/user/login                     # 用户登录
```

## ⚠️ 重要提示

### 1. 认证要求

所有测试用例管理接口都需要 JWT 认证：

```javascript
// 请求头
Authorization: Bearer <your_jwt_token>
```

### 2. 数据单位

- **时间**：毫秒（ms）
- **内存**：
  - 测试用例配置：MB
  - 判题结果：KB

### 3. 向后兼容性

- 旧的测试用例数据（没有 `time_limit`, `memory_limit`, `score`）仍然有效
- 前端需要处理这些字段为 `null` 或不存在的情况

### 4. 错误处理

所有接口都遵循统一的错误响应格式：

```json
{
  "code": 400,
  "message": "请求参数错误",
  "data": null
}
```
