一、用户模块 / 注册登录
注册/登录

学生注册：填写学号、姓名、手机号、密码，支持通过班级邀请码关联班级

教师注册：填写工号、姓名、手机号、密码，提交后进入管理员审核队列

校外学习者注册：填写姓名、手机号、密码，无需关联班级

密码找回：支持手机验证码重置，管理员后台可强制重置用户密码
首页

角色化登录跳转：超管→用户管理页，教师→课程管理页，学生/学习者→个人学习页

超管首页：包含系统所有用户管理、教师账号审核功能

教师首页：展示教师名下课程和班级信息

学生首页：展示已达成数据、所在班级待完成任务，设置核心功能快捷入口
用户设置

个人设置页：支持查看/编辑基础信息（姓名、手机号、头像），修改登录密码

会话管理：支持保持登录状态7天，设置token有效期

角色权限控制：防止越权访问，仅展示当前用户可见模块
二、班级与课程模块
课程模块

课程管理页：教师登录默认进入，展示课程名称、关联班级数、任务数、创建时间

课程创建：填写课程名称、学期、描述、授课时间，选择关联已创建班级

课程编辑/删除：编辑基础信息，删除前校验无关联任务、学生

课程详情页：展示课程完整信息、关联班级列表，支持修改信息、调整关联班级

课程成员管理：选择关联班级查看成员列表（学号、姓名、加入时间），支持移除成员

课程任务创建：填写任务标题、描述、时间，从题库选择题目添加至任务

课程任务列表：按创建时间倒序展示，标注状态（未开始/进行中/已结束）

课程任务操作：查看详情、编辑信息，删除前确认无学生提交记录

任务页面：展示任务信息、题目列表（名称、难度、分值），未开始任务可增减题目，学生可跳转答题
班级模块

班级管理页：教师通过侧边栏进入，展示班级名称、描述、成员数、创建时间

班级创建：填写班级名称、描述，系统生成6位邀请码+二维码

班级管理：查看成员列表，支持重置邀请码/二维码、关联已创建课程

班级删除：删除前校验无关联课程、任务

班级详情页：展示班级完整信息、邀请码/二维码、关联课程列表，查看成员详情并支持单个移除

班级关联课程查看：列出关联课程，点击名称跳转对应课程详情页
三、题库模块

题库首页：题目分页展示，支持按难度（简单/中等/困难）、标签（算法/数据结构等）筛选

题目卡片：展示标题、难度标签、通过率

题库搜索：支持题目标题、描述模糊搜索

题目详情页：展示完整描述、需求说明、输入输出格式、示例测试用例
四、代码在线编辑模块

在线编辑器：支持语法高亮、明暗模式切换、代码缩进和格式化

多语言支持：C、C++、Java、Python、JavaScript，切换语言同步题目基础代码

代码运行测试：使用当前代码运行可见测试用例，展示执行结果

代码提交判题：使用全部测试用例判题，展示执行结果（成功/失败）
