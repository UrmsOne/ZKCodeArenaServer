# Swagger/OpenAPI 集成指南

## 概述
本项目已集成 Swagger 2.0 (通过 swaggo)，用于自动生成和展示 REST API 文档。

## 依赖
已安装以下包：
- `github.com/swaggo/swag` - Swagger 文档生成工具
- `github.com/swaggo/gin-swagger` - Gin Swagger 中间件
- `github.com/swaggo/files` - 静态文件支持

## 集成步骤

### 1. 在 main.go 添加全局 API 信息

在 `cmd/main.go` 文件顶部添加：

```go
// @title           ZK Code Arena API
// @version         1.0
// @description     ZK Code Arena 在线编程平台 REST API 文档
// @termsOfService  http://localhost/terms/

// @contact.name   API Support
// @contact.url    http://localhost/support
// @contact.email  support@zkcodearena.com

// @license.name  MIT
// @license.url   https://opensource.org/licenses/MIT

// @host      localhost:8080
// @BasePath  /api/v1

// @securityDefinitions.apikey BearerAuth
// @in header
// @name Authorization
// @description Type "Bearer" followed by a space and JWT token.
```

### 2. 在 server.go 中注册 Swagger 路由

在 `pkg/app/api-server/server/server.go` 的 `RegisterRoutes` 方法中添加：

```go
import (
    // ... 现有 imports ...
    swaggerFiles "github.com/swaggo/files"
    ginSwagger "github.com/swaggo/gin-swagger"
    _ "zk-code-arena-server/docs"  // docs is generated by Swag CLI
)

func (s *Server) RegisterRoutes() {
    // ... 现有路由 ...

    // Swagger 文档路由
    s.app.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))
}
```

### 3. 为 Handler 添加 Swagger 注释

#### 注释格式说明
- `@Summary` - 简短描述
- `@Description` - 详细描述
- `@Tags` - 分组标签
- `@Accept` - 接受的 Content-Type
- `@Produce` - 返回的 Content-Type
- `@Param` - 参数说明 (格式: 参数名 参数位置 类型 是否必需 "描述" [可选: 默认值])
- `@Success` - 成功响应 (格式: 状态码 {响应类型} 模型 "描述")
- `@Failure` - 失败响应
- `@Router` - 路由路径和方法
- `@Security` - 安全认证要求

### 4. 生成 Swagger 文档

在项目根目录执行：

```bash
# 安装 swag CLI工具（如果未安装）
go install github.com/swaggo/swag/cmd/swag@latest

# 生成文档（会在项目根目录生成 docs/ 文件夹）
swag init -g cmd/main.go
```

生成的文件：
- `docs/docs.go`
- `docs/swagger.json`
- `docs/swagger.yaml`

### 5. 访问文档

启动服务后，访问：
```
http://localhost:8080/swagger/index.html
```

## 注意事项

1. **路径参数格式**：使用 `{id}` 而非 `:id`
2. **查询参数默认值**：使用 `default()` 指定
3. **枚举值**：使用 `Enums()` 限定可选值
4. **认证接口**：添加 `@Security BearerAuth`
5. **响应模型**：尽量使用已定义的 Go 结构体，复杂的内联对象使用 `object{}` 语法
6. **分组**：使用 `@Tags` 对接口分组，便于文档浏览
