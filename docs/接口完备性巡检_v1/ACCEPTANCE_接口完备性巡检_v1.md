## 实际修复问题

### 问题1: 配置解析错误
- **位置**: `conf/config.go`
- **问题**: `Server.Domain` 配置无法正确解析
- **修复**: 添加 `Server` 结构体到 `configYaml`

### 问题2: 参数绑定不一致
- **位置**: `server_course.go`
- **问题**: 部分接口使用 URL 参数，部分使用 JSON body，不统一
- **修复**: 统一使用 JSON body 接收请求参数

### 问题3: 权限控制不足
- **位置**: `server_problem.go`, `server_user.go`
- **问题**: 
  - `GetProblems` 无法区分公开/私有题目
  - `GetUserByID` 任何人都可以查看他人资料
- **修复**: 
  - 添加 `include_private` 参数和基于角色的过滤
  - 限制仅本人或管理员可查看用户资料
