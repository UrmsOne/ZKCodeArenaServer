## 📋 Issue 概述

基于成功的 go-judge 沙箱客户端实现，构建一个**统一的多语言判题服务**，通过配置驱动的方式支持多种编程语言，避免为每种语言单独构建服务的冗余。

## 🎯 设计目标

### 核心理念

- **统一接口**: 所有语言都通过相同的 `/run` 接口执行编译和运行
- **配置驱动**: 通过 `language-配置` 映射管理不同语言参数
- **逻辑一致**: 编译-运行-判题流程对所有语言保持一致
- **快速判断**: 提供题目级别的成功/失败状态，便于前端快速响应

## 📊 数据结构设计

### 状态定义

```go
// 测试用例状态
type JudgeStatus string
const (
    Accepted            JudgeStatus = "Accepted"
    WrongAnswer         JudgeStatus = "Wrong Answer"
    TimeLimitExceeded   JudgeStatus = "Time Limit Exceeded"
    MemoryLimitExceeded JudgeStatus = "Memory Limit Exceeded"
    RuntimeError        JudgeStatus = "Runtime Error"
    CompileError        JudgeStatus = "Compile Error"
    SystemError         JudgeStatus = "System Error"
)

// 题目状态 (快速判断)
type ProblemStatus string
const (
    ProblemSuccess      ProblemStatus = "Success"       // 所有用例 AC
    ProblemFailed       ProblemStatus = "Failed"        // 至少一个用例非 AC
    ProblemCompileError ProblemStatus = "Compile Error" // 编译失败
)
```

### 请求响应结构

```go
// 判题请求
type JudgeRequest struct {
    SubmissionID string      `json:"submission_id"`
    Language     string      `json:"language"`
    SourceCode   string      `json:"source_code"`
    TestCases    []TestCase  `json:"test_cases"`
}

// 判题结果 (题目级别 - 快速判断)
type JudgeResult struct {
    SubmissionID string         `json:"submission_id"`
    Status       ProblemStatus  `json:"status"`          // 快速判断: Success/Failed/CompileError
    CompileError string         `json:"compile_error,omitempty"`
    Cases        []CaseResult   `json:"cases"`
    Summary      ResultSummary  `json:"summary"`
}

// 单个用例结果 (详细信息)
type CaseResult struct {
    TestCaseID int         `json:"test_case_id"`
    Status     JudgeStatus `json:"status"`
    TimeUsed   int64       `json:"time_used"`     // 纳秒
    MemoryUsed int64       `json:"memory_used"`   // 字节
    Output     string      `json:"output"`
    ErrorMsg   string      `json:"error_msg,omitempty"`
}
```

## 🔄 核心判题流程

### 判题服务主流程

```go
func (js *JudgeService) Judge(ctx context.Context, req *JudgeRequest) (*JudgeResult, error) {
    // 1. 获取语言配置
    langConfig, err := js.getLanguageConfig(req.Language)
    if err != nil {
        return nil, fmt.Errorf("unsupported language: %s", req.Language)
    }

    // 2. 编译阶段 (如果需要)
    var executableId string
    if langConfig.Compile != nil {
        compileResult, err := js.compileCode(ctx, req.SourceCode, langConfig)
        if err != nil || compileResult.Status != "Accepted" {
            return &JudgeResult{
                SubmissionID: req.SubmissionID,
                Status:       ProblemCompileError,
                CompileError: js.filterJavaWarnings(compileResult.Files["stderr"]),
            }, nil
        }
        executableId = compileResult.FileIds[langConfig.Compile.ExecutableFile]
    }

    // 3. 运行测试用例
    var cases []CaseResult
    allPassed := true

    for i, testCase := range req.TestCases {
        caseResult := js.runTestCase(ctx, i, testCase, executableId, langConfig)
        cases = append(cases, caseResult)

        if caseResult.Status != Accepted {
            allPassed = false
        }
    }

    // 4. 生成结果
    status := ProblemFailed
    if allPassed {
        status = ProblemSuccess
    }

    return &JudgeResult{
        SubmissionID: req.SubmissionID,
        Status:       status,
        Cases:        cases,
        Summary:      js.generateSummary(cases),
    }, nil
}


```
